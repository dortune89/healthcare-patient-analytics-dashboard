# Healthcare Patient Analytics Dashboard

Interactive Excel dashboard analyzing a healthcare patient dataset (55,500 records).

## Features
- KPI Cards: Total Patients, Average Age, Average Billing, Total Revenue, Average Length of Stay
- Medical Condition Analysis
- Admission Type Distribution
- Billing by Insurance Provider
- Test Results Breakdown
- Interactive Slicers (Gender, Medical Condition, Admission Type, Insurance Provider, Test Results)

## How to use
1. Download the `.xlsx` file
2. Open it in Microsoft Excel
3. Use the slicers to filter and explore the data

## Data Source
https://www.kaggle.com/datasets/prasad22/healthcare-dataset
